# 功能与验证

适配目标为微软商店「中文输入法」1.0.0.17694。软件设置资源中的「自定义短语」「导入/导出自学习词库」「专业词库」「搜索建议」「模糊拼音」「自学习」和 V 模式用于确定本版本的功能范围。[微软商店应用](https://apps.microsoft.com/detail/xpfpt96q7b9s4n?gl=CN&hl=zh-CN)

## 本机已验证

- 全拼、简拼、拼写纠错和本地候选排序由 `MAI_ChsPinyinDS.dll` 生成。简拼 `zwsrf` 通过 Fcitx5 在 GTK 输入框中上屏为「中文输入法」。数字键可以按引擎原顺序选词。
- 分段选词读取微软候选数据里的已匹配拼音。在 `zhongwenshurufa` 中先选「中文」，剩余的 `shurufa` 继续查询微软引擎，再选择「输入法」。
- 本地候选排序学习使用微软数据源的选词反馈和用户历史文件。在独立前缀通过 GTK 选「试验」两次后，重启进程再打 `shiyan`，空格提交「试验」。
- 网页可开关原版自动纠错、模糊音和本地自学习。网页端到端实验关闭纠错后，`nihoa` 首选由「你好」变为「你吼啊」。启用 `z / zh` 后，`zongguo` 首选由「总过」变为「中国」。
- Fcitx5 显示与快捷键已验证分段、中文标点、Shift 切换英文与全角数字。候选页数在三至九之间可调。

## 已做引擎实验

- 云候选模块 `MAI_ChsProxyDS.dll` 已经通过 Wine 向微软线上服务发出真实请求。七组固定测试拼音收到 HTTP 200 和零条候选，其中一组核对了正文中的 `FullResults: 0`。正式服务以离线模式运行。
- 原包的 `MAI_ChsAdvancedDS.dll` 可在 Wine 初始化。V 模式数值、日期和公式测试调用返回空列表，继续适配需要确认 Windows 前端送给数据源的完整查询字段。
- 个人短语管理、自学习词库导入导出、专业词库开关、候选固定和删除、上下文短语以及必应搜索建议仍待完成端到端验证。运行中的本地自学习与设置资源中的词库导入导出分别对应不同功能。
